# App Store Review Notes

## Reviewer Guidance

HashWatch is a monitoring tool for BitAxe Bitcoin mining hardware. It does NOT:

- Mine cryptocurrency on the user's device
- Contain any in-app purchases that unlock mining capability
- Facilitate gambling or betting

The app reads hardware sensor data from locally-networked BitAxe devices and presents it in a dashboard.

## Test Account

- Email: review@hashwatch.app

The app requires network access to BitAxe miners on the local network. For review purposes, the app functions in demo mode when no miners are detected, showing sample data and all features.

## Key Features to Review

1. Dashboard with real-time miner stats
2. Fleet health with predictive maintenance
3. Settings with 14 theme options
4. Activity feed showing miner events
5. World map view with miner locations

## Privacy

- We do not collect personal data beyond email for account creation
- All miner data is stored locally and optionally synced to our servers
- No third-party analytics beyond Plausible (privacy-friendly)
- Full privacy policy at https://hashwatch2.vercel.app/privacy
